# Зимние события — Парк «Сказка»

Публичный лендинг зимних корпоративных событий Парка «Сказка». Сайт собран на Next.js/vinext и автоматически публикуется в GitHub Pages.

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

После `npm run build` статическая версия появляется в `dist/client`.

## Публикация

Каждый push в ветку `main` запускает GitHub Actions и обновляет GitHub Pages.
